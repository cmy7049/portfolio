# ROS2 및 LiDAR 기반 센서 매핑

오션플랜(현장실습)에서 자율주행 시스템의 기초를 학습하고, ROS2 프레임워크로 LiDAR 센서 매핑을 실습했습니다.

---

### 역할

실습생 (현장실습)

### 사용 기술

Ubuntu OS, ROS2(Robot Operating System 2), LiDAR 센서

---

### 실습 내용

자율주행 시스템 자료 정리를 하며 기본 내용을 숙지한 후, Ubuntu OS 환경에서 ROS2 프레임워크를 활용해 LiDAR 센서를 연동하여 주변 환경 데이터 수집의 기초를 배웠습니다.

이 과정을 통해 자율주행을 위한 실시간 데이터 수집 및 시각화 프로세스를 이해했습니다.
