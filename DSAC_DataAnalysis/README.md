# DSAC 데이터 분석 과정

Jupyter Notebook에서 Python·Pandas를 활용한 데이터 전처리와 Matplotlib 시각화 역량을 확보하고, 회귀분석과 머신러닝으로 데이터의 변수 간 상관관계를 분석했습니다.

**DSAC 2급 (데이터 사이언티스트 자격, 한국생산성본부) 2024.07 취득**

---

### 사용 기술

Python, Pandas, Matplotlib, Jupyter Notebook, 회귀분석, 머신러닝

---

### 학습 내용

- 데이터 전처리 : Python·Pandas를 활용한 결측치 처리, 이상치 탐지, 데이터 정제
- 시각화 : Matplotlib으로 공정 데이터 시각화
- 분석 : 회귀분석과 머신러닝으로 변수 간 상관관계 분석

이를 통해 공정 품질 및 장비 효율을 정량적으로 판단할 수 있는 문제 해결력을 키웠습니다.
