# 부산권 파워반도체인재양성센터 — 8개 트랙 이수

174시간 이상의 겨울 방학 집중 교육을 통해 소자 설계, 공정 실습, 장비 기술, 시장 분석까지 반도체 전 영역을 학습했습니다.

**2025.01 ~ 2026.02 | 174시간 | 글로벌 반도체 마케팅 최우수상 🏆**

---

### TCAD 소자 설계 → 팹 제조

Synopsys Sentaurus와 SILVACO로 도핑 프로파일과 전기적 특성을 시뮬레이션한 뒤, 동일 구조를 팹에서 직접 제조하며 시뮬레이션과 현실의 간극을 체감했습니다.

TCAD로 설계한 NMOS 소자를 실제 팹에서 직접 제작하는 전 과정을 경험했습니다.

---

### 공정 비가역성 체득

제조 과정에서 가장 인상 깊었던 것은 공정의 비가역성이었습니다. 포토 공정은 에탄올로 PR을 제거하면 리워크가 가능하지만, 식각은 한 번 진행되면 되돌릴 수 없었습니다. 실제로 웨이퍼가 죽는 것을 눈앞에서 확인하며, 식각 장비의 공정 안정성이 곧 수율이라는 것을 몸으로 배웠습니다.

클린도가 다른 팹 환경에서 웨이퍼 표면의 결함 양상을 육안으로 비교 관찰하며 파티클 관리의 중요성을 확인했고, 노광 시 Align Key를 직접 정렬하며 장비 상태가 공정 결과에 직접 영향을 미친다는 것을 체득했습니다.

---

### 장비 제어 및 시장 분석

장비기술 트랙에서는 XG5000으로 PLC 시퀀스 제어와 진공 펌프 원리를 실습하며 장비 자동화 제어의 기초를 다졌습니다.

글로벌 반도체 마케팅 트랙에서는 인텔 모빌아이 ADAS 기술을 SWOT 분석으로 연결하여 시장 전략을 도출한 결과, 최우수상을 수상했습니다.
