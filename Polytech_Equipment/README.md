# 한국폴리텍대학교 하이테크과정 — PLC 전장 제어, PECVD 설계, SPC 분석

반도체 융합기계 하이테크 과정(528시간 이수 중)을 수행하며, 장비 제어·구조 이해·품질 분석 역량을 동시에 습득하고 있습니다.

**2026.03 ~ 현재 | 1200시간 과정**

---

### 사용 기술

- PLC : Mitsubishi MELSEC Q5, GX-Works2/3, LS XG-5000
- HMI : M2I 화면 설계
- 3D 설계 : SolidWorks (3D 모델링/어셈블리/도면 해독)
- 품질 분석 : Minitab(Cp/Cpk), FMEA/8D Report

---

### PLC 장비 제어 및 인터록 설계

Mitsubishi PLC(GX-Works2/3, MELSEC Q5)와 XG-5000으로 3상 인버터 컨베이어와 지능형 신호 제어 시스템을 구축했습니다. 설비 기동 시 사용자가 전혀 모른다고 가정하고 PLC가 '동작'보다 '정지'에 더 큰 가치를 두도록 인터록을 설계했습니다.

---

### 솔레노이드 밸브 트러블슈팅

실습 중 솔레노이드 밸브가 PLC 신호에 반응하지 않아 즉시 차단기를 내리고 릴레이 배선을 추적하여 쇼트 지점을 발견했습니다. 회로도를 직접 그려 동료들에게 원인을 설명한 뒤 GX Works3 래더 로직을 수정하여 정상 동작을 확인했습니다.

---

### SolidWorks PECVD 장비 3D 모델링

SolidWorks로 챔버 바디, 샤워헤드, 서셉터 등 반도체 장비 핵심 파츠를 3D 어셈블리하며 가스 배관과 RF 전극의 공간 배치를 학습하고, PECVD 장비 구조를 입체적으로 파악했습니다.

실제 PECVD 장비의 2D 도면(부품도 + 조립도)을 KS 규격에 따라 해독하고, SolidWorks에서 개별 부품을 3D 모델링한 후 전체 Assembly로 조립했습니다.

---

### SPC 기반 데이터 분석

생성형 AI를 활용하여 식각 균일도, 증착 두께 등 반도체 공정의 가상 데이터를 생성한 뒤, 이 데이터로 8D Report를 작성하며 불량의 근본 원인을 단계별로 추적하는 프로세스를 실습했습니다.

FMEA를 통해 잠재적 고장 모드와 RPN을 산출했습니다. AI가 시각화한 결과를 직접 Minitab으로 동일하게 분석하여 N=160개 샘플의 Cp/Cpk를 산출하고 히스토그램·관리도로 공정 산포를 시각화하여, AI 출력과 실제 통계 분석 간 차이를 교차 검증하고 보정했습니다.
