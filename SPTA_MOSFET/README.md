# SPTA — 4-Mask MOSFET 제작 및 수율 분석

P-type Si Wafer에 4-Mask 공정을 적용하여 N-Type MOSFET을 직접 제작하고, 22개 Die의 전기적 특성 분석을 통해 오버에칭 Root Cause를 도출했습니다.

**2025.12 ~ 2026.01 | 반도체공정기술교육원 (32시간)**

---

### 사용 장비

PROwin SP-6SM150S(포토), KVET-R2000 RIE(건식 식각), 울텍 SEE-5 Evaporator(Al 전극 증착), SEM, Probe Station, Keysight I-V Analyzer

---

### 22개 Die 전기적 특성 분석 — 오버에칭 Root Cause 도출

Dry Etch와 Wet Etch를 순차 적용해 식각 프로파일과 선택비를 확보한 뒤, 완성된 웨이퍼 내 22개 Die에 대해 프로브 스테이션으로 ID-VD, ID-VG 특성을 측정했습니다.

중앙부 2개 Die에서 누설 전류 이상을 발견했습니다. 단순 불량 처리하지 않고 원인을 끝까지 추적하여, 산화막 두께 편차, 포토레지스트 잔류, 금속 배선 불량, 이온 주입 산포, 습식 식각 시간 초과의 5가지 가설을 수립했습니다.

각 공정 단계의 파라미터를 대조한 결과, 습식 식각 침지 시간이 매뉴얼 대비 약 5초 초과된 것을 검출하여 오버에칭으로 하부 막질이 과도하게 제거되어 쇼트가 유발된 것이 근본 원인임을 도출했습니다.

EPD 제어를 통한 정밀한 장비 파라미터 세팅이 Over/Under Etch를 방지하고 소자 수율을 결정하는 핵심임을 체감했습니다.

---

### 계측 기준 표준화 및 장비 정밀도 체감

4-Mask 공정으로 웨이퍼 패터닝을 수행한 후, SEM 장비를 활용해 웨이퍼의 지점별(Left/Center/Right) Gate 및 Line CD를 정밀 계측했습니다.

제한된 시간 내에 측정자별 기준 차이로 데이터 편차가 2μm 이상 발생하여, 팀원 간 측정 기준을 직접 협의하고 표준화하여 계측 오차를 최소화했습니다.

고배율에서 차징과 스테이지 드리프트로 동일 지점 반복 측정 시에도 값이 흔들리는 것을 관찰하며 장비 정밀도의 중요성을 체감했습니다. 산출된 공정 데이터를 직접 분석·시각화하는 과정을 거치며, 미세한 계측 오차가 수율에 미치는 영향을 이해하는 실무적 데이터 분석 감각을 길렀습니다.
